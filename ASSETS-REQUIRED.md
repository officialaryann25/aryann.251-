# IceWorld - Required Assets List

This document lists all the image assets needed to complete the IceWorld website. Currently, the website uses SVG placeholders with emoji fallbacks. Replace these with actual high-quality images for production.

## Image Requirements

### General Specifications
- **Format**: JPG or PNG (WebP for modern browsers)
- **Optimization**: Compress for web (aim for under 500KB per image)
- **Quality**: High resolution for retina displays
- **Naming**: Use lowercase with hyphens (e.g., `chocolate-dream.jpg`)

## Optimization Tips

### Before Upload:
1. **Resize**: Use exact dimensions specified above
2. **Compress**: Use tools like TinyPNG, ImageOptim, or Squoosh
3. **Format**: 
   - JPG for photos (quality: 80-85%)
   - PNG for graphics with transparency
   - WebP for modern browsers (with fallback)
4. **File Size**: Aim for:
   - Hero images: < 300KB
   - Product images: < 200KB
   - Icon/small images: < 100KB

### After Upload:
1. Replace placeholder image paths in HTML files
2. Remove `onerror` attributes once real images are in place
3. Test all pages to ensure images load correctly
4. Verify mobile responsiveness
5. Check loading performance
