# IceWorld - Premium Artisanal Ice Cream Website

A modern, luxury, multi-page website for IceWorld, featuring premium design aesthetics, smooth animations, and fully functional navigation.

## 🍦 Project Overview

IceWorld is a premium ice cream brand website built with modern web technologies and designed with a luxury aesthetic. The website showcases handcrafted artisanal ice cream offerings through five beautifully designed pages.

## ✨ Features

- **Modern Luxury Design**: Premium color palette with soft pastels, chocolate tones, and cream colors
- **Glass Morphism Effects**: Sophisticated backdrop blur and translucent elements
- **Smooth Animations**: ScrollReveal.js powered animations throughout the site
- **Fully Responsive**: Mobile-first design that works perfectly on all devices
- **Interactive Components**: Hover effects, lightbox gallery, category filters, and more
- **SEO Optimized**: Proper meta tags, semantic HTML, and accessibility features

## 📄 Pages

1. **Home (index.html)** - Landing page with hero section, popular flavors, and brand showcase
2. **Menu (menu.html)** - Complete product catalog with category filters and "Add to Cart" functionality
3. **Gallery (gallery.html)** - Beautiful image gallery with lightbox functionality
4. **About (about.html)** - Brand story, values, founders, and statistics
5. **Contact (contact.html)** - Contact form, business hours, map, and owner information

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Web server (optional, for local development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/officialaryann25/aryann.251-.git
cd aryann.251-
```

2. Open in browser:
   - Simply open `index.html` in your browser
   - Or use a local development server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (with http-server)
   npx http-server
   ```

3. Visit `http://localhost:8000` in your browser
